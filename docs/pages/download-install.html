Download and install

Install the native plugin files for your operating system, then copy the supplied template to a writable user directory.

Download

Download Fly Scoreboard

Close OBS Studio before replacing an existing plugin. Choose the build matching your operating system and OBS architecture.

Plugin locations

Windows

%ProgramFiles%\obs-studio\obs-plugins\64bit\fly-scoreboard.dll
%ProgramFiles%\obs-studio\data\obs-plugins\fly-scoreboard\locale\
%ProgramFiles%\obs-studio\data\obs-plugins\fly-scoreboard\templates\

For portable OBS, use the equivalent paths below the portable OBS root.

macOS

~/Library/Application Support/obs-studio/plugins/fly-scoreboard.plugin

The executable, locales, and supplied templates are contained in the plugin bundle's standard Contents directories.

Linux

/usr/lib/obs-plugins/fly-scoreboard.so
/usr/share/obs/obs-plugins/fly-scoreboard/locale/
/usr/share/obs/obs-plugins/fly-scoreboard/templates/

The library prefix may be /usr/lib64 or a distribution-specific multiarch directory.

Copy the template before use

Required: Do not activate a template inside Program Files, an application bundle, or /usr. Fly writes plugin.json and may copy logo files into the active template directory.
PlatformRecommended writable location
Windows%USERPROFILE%\Documents\Fly Scoreboard\Templates\Modular Football
macOS~/Library/Application Support/Fly Scoreboard/Templates/Modular Football
Linux${XDG_DATA_HOME:-$HOME/.local/share}/fly-scoreboard/templates/Modular Football
OBS Flatpak~/.var/app/com.obsproject.Studio/data/fly-scoreboard/templates/Modular Football
  1. Locate the supplied templates/Modular Football directory.
  2. Copy the complete directory to the appropriate writable location above.
  3. Start OBS and open the Fly Scoreboard dock.
  4. Click Template Folder... and select the copied Modular Football directory itself.

Verify the plugin

  1. Start OBS Studio.
  2. Open Tools and enable the Fly Scoreboard dock.
  3. Confirm that the dock shows the active template name and an online local WebSocket status.
