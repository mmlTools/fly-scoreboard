Event Logs & Timestamps

Fly can write chapter-ready text logs for goals, score changes, stats, timers, and operator notes.

Use it from the dock

  1. Open the Events tab.
  2. Choose Stream time for 0:12:34 timestamps or Real time for date-and-clock timestamps.
  3. Start streaming/recording, or press Start log. OBS streaming and recording events start a log automatically.
  4. Use the event box for notes such as Penalty or Shot on Goal. Score, stat, timer, visibility, and side changes are captured automatically.
  5. Press Folder to open the log directory.

Use it from a controller or live-data feeder

{"action":"start_event_log","label":"Stream Start"}
{"action":"log_event","label":"Penalty: Eagles #12"}
{"action":"stop_event_log","label":"Stream End"}

How files behave

  • Each session creates a unique fly-scoreboard-YYYYMMDD-HHMMSS-milliseconds.txt file.
  • Logs are stored in the plugin configuration directory under event-logs, not inside a theme, so changing themes does not move them.
  • Event labels are kept on one line so the file is safe to parse for chapters or clip automation.
  • The selected timestamp mode is remembered for the next OBS session.
For automatic clips, watch the log directory and react to a stable prefix such as Score: or send explicit log_event labels from your controller.
