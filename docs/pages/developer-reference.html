Tags & Developer Reference

Build a complete Fly Scoreboard theme from ordinary HTML and CSS. This page lists every template binding, data path, derived value, and the practical workflow for adding scores, stats, and timers.

Smallest valid theme

Put each theme in its own folder. The folder must contain these files:

my-scoreboard/
  index.html       # layout and Fly tags
  panel-a.html     # optional independent Browser Source panel
  panel-b.html     # another independently managed panel
  manifest.ini     # title, author, author_url, description, version
  script.js        # copy from the bundled overlay runtime
  style.css        # your design
  plugin.json      # created when this folder is activated in the dock
title=My Scoreboard
author=Your Name
author_url=https://example.com
description=A responsive match scorebug
version=1.0.0

All Fly HTML tags and bindings

SyntaxUseExample
{{path}}Insert a live value into text.{{team_x.title}}
{{path}} in an attributeBind an image, CSS variable, ARIA label, class, or other attribute.src="{{team_x.logo}}"
{{condition ? 'a' : 'b'}}Choose one of two literal strings.class="{{show_scoreboard ? 'board' : 'board hidden'}}"
fs-if="condition"Show an element only when the condition is true.fs-if="timers[1] && timers[1].visible"

fs-if supports paths, !, &&, ||, and parentheses. Array indexes are zero-based. There are deliberately no loops or arbitrary JavaScript expressions.

Add a score and bind it to HTML

  1. Open Stats… in the dock and add a Team stat named Score.
  2. Note its position. The first row is index 0, the second is 1.
  3. Bind the swap-safe x/y values in the theme.
<section class="score" fs-if="fields_xy[0] && fields_xy[0].visible">
  <span>{{team_x.title}}</span>
  <strong>{{fields_xy[0].x}} – {{fields_xy[0].y}}</strong>
  <span>{{team_y.title}}</span>
</section>

You can also create it remotely:

{"action":"add_score","label":"Score","home":0,"away":0,"visible":true}
{"action":"bump_score","index":0,"side":"home","delta":1}
{"action":"set_score","index":0,"side":"away","value":3}

Add a single stat and bind it

<div fs-if="single_stats[0] && single_stats[0].visible">
  {{single_stats[0].label}} {{single_stats[0].value}}
</div>
{"action":"add_single","label":"PERIOD","value":1,"visible":true}
{"action":"bump_single","index":0,"delta":1}

Add a timer and bind it

  1. Open Timers…, add a timer, choose count up/down, and set its initial time.
  2. Render mmss for sports clocks or hhmmss for long sessions.
  3. Guard every optional timer with fs-if.
<div class="clock" fs-if="timers[0] && timers[0].visible">
  <span>{{timers[0].label}}</span>
  <time>{{timers[0].mmss}}</time>
</div>
{"action":"add_timer","label":"Period 1","mode":"countdown","initial_ms":1200000,"visible":true}
{"action":"timer_start","index":0}
{"action":"timer_pause","index":0}
{"action":"timer_reset","index":0}

Developer tips and tricks

  • Design on the full OBS base canvas. Place a compact scorebug with CSS; resize or reposition its Browser Source using the red handles in the OBS preview.
  • Prefer team_x, team_y, fields_xy, and fields_by_key. They make side swapping work without custom JavaScript.
  • Give each independently positioned panel its own HTML entry point. Share the runtime and stylesheet instead of combining every component into one page.
  • Guard every optional array entry before binding it: fs-if="fields_xy[3] && fields_xy[3].visible".
  • Keep the bundled script.js unchanged when possible. Put theme-specific behavior in a second script so runtime upgrades are easy to merge.
  • Use CSS custom properties in bound style attributes: style="--team-color: {{team_x.color}}".
  • Use font-variant-numeric: tabular-nums on scores and clocks to prevent layout jitter.
  • Make the theme transparent: html, body { margin: 0; background: transparent; overflow: hidden; }.
  • The WebSocket is the fast path; plugin.json polling is the automatic fallback.
  • Test missing logos, long names, double-digit scores, side swapping, hidden rows, and disconnected WebSocket before going live.
Fly has no OBS source selector or source-management API. Choose only the writable template folder in the dock. Load, position, crop, and show each HTML entry point yourself in OBS; their shared state keeps them synchronized.
