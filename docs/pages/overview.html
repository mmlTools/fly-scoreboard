Overview

Fly Scoreboard is an OBS Studio plugin that broadcasts live scoreboard state over a local WebSocket, keeps a plugin.json fallback on disk, and ships a lightweight overlay runtime that renders your scoreboard by replacing template placeholders ({{…}}) in HTML.

What you get

  • A dock UI to manage teams, scores, timers, and single stats.
  • A modular football package with separate scoreboard, fouls, cards, and corners HTML files.
  • Local remote control through ws://127.0.0.1:4457.
  • A small templating engine: write {{home.title}}, {{timers[0].mmss}}, etc.

How it works

  1. The plugin updates state in memory and writes plugin.json.
  2. Every independent panel receives pushes from the same local WebSocket, then falls back to polling the shared plugin.json.
  3. An animation loop renders timers smoothly and applies template replacements every frame.

Quick start

  1. Install the plugin.
  2. Click Template Folder… and choose the writable template directory itself. The dock has no source-selection dropdown.
  3. Manually add index.html as the scoreboard Browser Source.
  4. Add fouls.html, cards.html, and corners.html as separate Browser Sources where needed.
  5. Arrange each source independently, customize teams and match values, then go live.
Tip: Keep all module HTML files, style.css, script.js, and plugin.json in the same folder. The default overlay runtime connects to ws://127.0.0.1:4457 first and fetches plugin.json by relative path as a fallback.
