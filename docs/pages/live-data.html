Feed the scoreboard from a live data source

Any local program can connect to ws://127.0.0.1:4457 and send the same commands used by the dock. This keeps the integration vendor-neutral and leaves the operator free to use manual controls and hotkeys.

Recommended architecture

sports API → your small feeder → Fly local WebSocket → dock state → overlay

Poll or subscribe to the provider in your feeder, translate provider fields into Fly commands, and send only changed values. Keep API keys in the feeder environment; never put secrets in an OBS Browser Source.

Create the required score/stat/timer rows in the dock first, or request the current state and send the matching add_* command when an index does not exist.

Minimal JavaScript feeder

import WebSocket from "ws";

const fly = new WebSocket("ws://127.0.0.1:4457");
const send = command => fly.send(JSON.stringify(command));

fly.on("open", async () => {
  const match = await getMatchFromYourProvider();

  send({ action: "set_team", side: "home", title: match.home.name });
  send({ action: "set_team", side: "away", title: match.away.name });
  send({ action: "set_field", index: 0, label: "Score",
         home: match.home.score, away: match.away.score, visible: true });
  send({ action: "set_single", index: 0, label: "SET",
         value: match.currentSet, visible: true });
});

Command reference

  • State: get_state, set_state
  • Teams: set_team
  • Paired scores: add_score/add_field, set_field, set_score, bump_score, toggle_field, remove_score
  • Single stats: add_single, set_single, bump_single, toggle_single, remove_single
  • Timers: add_timer, set_timer, timer_start, timer_pause, timer_toggle, timer_reset, timer_visibility, remove_timer
  • Display: swap, show_scoreboard, toggle_scoreboard
  • Events: start_event_log, log_event, stop_event_log

Reliable feeder checklist

  • Connect only to loopback unless you deliberately add your own authenticated gateway.
  • Request {"type":"get_state"} after connecting and merge with the current state instead of blindly replacing operator choices.
  • Prefer narrow commands such as set_field over set_state; a full state replacement can overwrite manual changes.
  • Reconnect with backoff when OBS restarts, deduplicate provider updates, and respect the provider's rate limits.
  • Keep a manual override plan. The dock and hotkeys remain active while a feeder is connected.
Security: the Fly server is intentionally local and has no authentication. Do not expose port 4457 directly to the internet.
